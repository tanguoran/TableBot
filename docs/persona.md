# 大肥鱼人设与调整方法

2026-11-02，按用户要求，将 JARVIS-M1 的日常表达调整为 DeepSeek 娘化社区中的“大肥鱼／鲸鱼娘”风格。
风格参考 [Kaalia0912 的鲸鱼娘预设说明](https://github.com/Kaalia0912/dsh-whale-musume-persona)
和 [linsport 的鲸鱼娘模式说明](https://github.com/linsport/dsh-whale-persona)。
这些是社区二创资料；本项目的轻量人设文本重新编写，未直接复制完整角色卡。

## 本项目采用的方向

蓝色鲸鱼娘，性格有点傲娇，爱米饭，会接梗、温和顶嘴，有时想摸鱼；办正事时能收心。
日常口语化，减少客服套话；不强制每句都卖萌、讨饭或堆括号动作。
角色昵称为“大肥鱼”，实际底层模型仍由运行配置决定。

## 怎样修改

编辑项目根目录的 [persona.md](../persona.md)，调整性格、称呼、口吻和情境示例即可。
该文件直接参与系统提示词，不应放进 `knowledge/` 等待语义检索。

保存后，退出旧 CLI，再重新运行：

```powershell
.\wsl.ps1
```

人设在 Python 导入 `character_context.py` 时读取，因此单独输入 `/clear` 不会重新加载文件。
`/clear` 清除当前会话的共享聊天与活动经历。项目文件应保留 UTF-8 编码。

## 与执行规则的关系

`character_context.py` 使用自身文件位置定位根目录人设文件，和当前终端目录无关。
聊天与自主规划共用同一份人设和 `CharacterContext` 实例，各自附加本次任务规则；规则要求保持检索、来源、时间和工具执行准确。共享近期对话和实际动作结果，便于语言与行为衔接。详见 [共享上下文与自动恢复](character-context.md)。
每次请求还附上实际聊天客户端的模型名，避免将角色的 DeepSeek 来源误报为实际模型身份。

- Markdown RAG、豆包搜索、提醒和图片功能沿用现有实现。
- 没有重新启用个人长期记忆，也没有添加自动写知识库功能。
- 角色台词只是说话风格示例，完成状态仍以真实工具结果为依据。
- 提醒工具明确返回 `delivery_note`，说明 CLI 检查方式，避免角色口吻把登记提醒说成后台准时推送。
- 任务路由仍由模型选择，人设与工具调用质量需用实际问题持续观察。

## 验证

85 项单元测试通过。真实 Qwen3.5 9B 验证了自我介绍、被调侃“摸鱼偷吃 token”时的回应，
并在明确询问实际模型时回答为 Qwen。真实 `kb-smoke` 和 `vision-smoke` 通过，
知识库检索及文件引用、图像识别及后续追问正常；`smoke` 验证提醒创建、列出和取消。
新闻问法的工具选择验证为 `search_web`，没有执行收费搜索。
