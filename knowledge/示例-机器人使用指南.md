# JARVIS 桌面机器人使用指南

这是随项目附带的演示资料。你可以直接编辑或删除本文件，并放入自己的 Markdown 文档。

## 查看与修改知识库

在项目的 knowledge 目录中新建 Markdown 文件即可添加资料，也支持建立多级子目录。
建议一份文件围绕一个主题，用一级标题命名文档，用二级标题划分章节。
保存修改后，下一次知识库查询会自动同步；在聊天中输入 /kb-sync 可以提前同步索引。
输入 /kb 可以查看知识库目录和当前索引数量。

## 退出对话

在终端输入 /quit 可以退出当前对话程序。输入 /clear 可以清除短期聊天上下文。
清除短期上下文不会删除知识库 Markdown 文件，也不会删除已保存的长期记忆。
